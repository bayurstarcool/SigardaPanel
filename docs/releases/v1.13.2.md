SigardaPanel v1.13.2

The license public key is now part of the code, so every build can verify licenses.

- v1.13.0 and v1.13.1 were built without the license public key (the build variable was not set): they could not verify any license and ran on the free tier. v1.13.2 carries the key in internal/license/keys.go; licenses activate and check-in delivers them.
- Everything else is as in v1.13.0 (see its notes).

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

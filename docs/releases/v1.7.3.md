SigardaPanel v1.7.3

Disk usage in the sidebar
- The sidebar showed only a used figure with an empty bar for accounts without a disk limit. Since v1.7.2 it also counted only an admin's own sites, so an admin whose sites belong to other users saw 0. It now always shows "used / total":
  - with a disk limit: the sites you own, against the limit (what the limit is enforced on);
  - an admin without a limit: every site on the panel, against the disk capacity of all servers;
  - anyone else without a limit: your own sites, against the disk capacity of the servers they are on.
- The sidebar refreshes the figure every minute, and every 15 seconds while sites are still being measured. Before, it was read once and kept showing the first (possibly incomplete) result until the page was reloaded.
- The user page shows the same scope and capacity for users without a limit.

Measuring needs the site's agent: update the agent on every server after upgrading the panel. Server capacity comes from the server metrics, so a server whose agent does not report metrics does not add to the total.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.14.1

Panel update can use the GitHub account a super admin connected.

- A panel that updates from a private release repository (the master panel) no longer needs SIGARDAPANEL_UPDATE_TOKEN in panel.env when a super admin has connected GitHub (github.com) under Git integration and that account can read the repository: checking for releases and installing them use that connection's token. SIGARDAPANEL_UPDATE_TOKEN still takes precedence when it is set.
- The token reaches the installer in a 0600 file in the update's state directory that is removed when the run ends, never in the update unit's environment (readable by every local user through systemctl show) or on a command line.
- The "needs a token" message now names both options.
- Public panels are not affected: their releases are public.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

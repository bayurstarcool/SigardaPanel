SigardaPanel v1.13.3

The license public key now matches the master panel.

- v1.13.1 and v1.13.2 carried a license public key whose private key the master panel (panel.sigarda.com) does not hold: licenses from the master, including the free license from check-in, were refused. v1.13.3 carries the master's key (internal/license/keys.go); licenses activate and check-in delivers them.
- No license was ever issued with the old key, so nothing that worked stops working.
- Everything else is as in v1.13.0 (see its notes).

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.12.2

vCPU counts and a consistent Local Server address.

- The Specs and System pages show the vCPUs first: the CPUs the system runs (what nproc reports and what providers sell). Hypervisors often present 2 vCPUs as 1 core with 2 threads, which these pages showed as "1 core"; the presented cores × threads are now shown as detail.
- The agent corrects a CPU topology that cannot hold the CPUs (for example every vCPU reporting the same core id without thread siblings).
- The Local Server entry takes the public IPv4 of SIGARDAPANEL_PUBLIC_URL (the address the installer chose) instead of detecting it again, which could differ on hosts with several addresses or a NAT whose outbound address is not the inbound one.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

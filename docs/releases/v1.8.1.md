SigardaPanel v1.8.1

Database viewer: filters instead of free SQL
- The viewer's SQL tab is replaced by filters on the Data tab: pick a column, an operator (=, ≠, contains, starts with, >, ≥, <, ≤, is NULL, is not NULL) and a value, then Apply. Several filters combine with AND, and they work with sorting and pages.
- No SQL text from the browser reaches the database any more: table and column names come from the database's own catalog, and filter values, limits and offsets are sent as bound parameters. This also clears the code-scanning alerts on v1.8.0. For hand-written queries use phpMyAdmin (MySQL).

SSH/SFTP: the account's Linux user id is taken from the site's Linux user instead of from the site folder (same result, no path from the request is read).

Update the agent on every server after upgrading the panel: the viewer and SSH changes run on the agent.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

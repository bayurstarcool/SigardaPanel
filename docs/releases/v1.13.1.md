SigardaPanel v1.13.1

The license public key is built in again.

- v1.13.0 was built without the license public key: it could not verify any license (activation refused, free licenses from check-in refused) and ran on the free tier. v1.13.1 is the same code with the key; licenses activate and check-in delivers them.
- Everything else is as in v1.13.0 (see its notes): signed licenses with daily check-in, the default site page, security fixes, private release repositories.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.12.4

Every site shows the logs of its own runtime.

- Node.js, Python and Go apps write their output (stdout and stderr) to their own log, /var/log/sigardapanel/apps/<domain>.log, readable by root only, rotated weekly or at 50 MB (4 kept) and removed with the site. Apps started before this version are read from the system journal until their next start or restart. Python output shows up immediately (PYTHONUNBUFFERED).
- The site's Logs tab lists the logs of its runtime and opens on the most relevant one: the app's output (Node.js, Python, Go), the container (Docker), PHP-FPM (PHP), nginx errors (static, proxy). Every site, Docker included, also has its nginx error and access logs.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents); an older agent cannot read app logs and the Logs tab says so.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.17.0

Simple plans: every feature on every plan, plans set the number of servers.

- Licensing: the Free plan now includes every feature (databases and the database manager, Node.js/Python/Go/Docker runtimes, git deploy, monitoring and alerts, scheduled and cloud backups, users and roles, Cloudflare, audit log, ...) with no limit on sites. Paid plans raise the number of servers one panel manages: Free 1 (the panel host), Basic 3, Pro 10, Enterprise 50, Max unlimited (a key can set its own number); Enterprise and Max also include white label and priority support.
- The server count is enforced when a server is added (Servers -> Add server, or the agent install command registering a new server). A re-install of an agent that is already registered is not counted, and existing servers keep working whatever the plan. When the limit is reached, Add server explains it and links to the upgrade page. Before, the panel showed limits (1 server, 5 sites, "Pro" features) that were not applied at all.
- The license card shows the real number of sites and "Unlimited" where it applies.
- New sites and databases: creating a PHP site on a server without PHP, or a database on a server without MariaDB/MySQL or PostgreSQL, is now refused at once with a clear message (install it under Servers -> Stack) instead of a site or database whose job fails later with a technical error. The agent's own messages for these cases were made readable too.

Checked on a fresh Ubuntu 24.04 server: install (about 2 minutes, Node.js 22 installed automatically), first login and password change, Local Server and agent, static site, PHP and MariaDB from the Stack page, PHP site and database, survival of a reboot, and the license chain with panel.sigarda.com (free license delivered at the first check-in, verified offline with the release key and bound to the installation).

Update the agents on remote servers after updating the panel (Settings -> Panel update -> Agents).

Panels on v1.15.0 or older must update once by hand (see the v1.16.0 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.9.0

Security: the panel's HTTP framework moves from echo v4 to echo v5.4.5.
- echo v4 is affected by two advisories with no fix for v4: GO-2026-6875 (the reverse proxy forwards a client-supplied X-Real-IP) and GO-2026-6872 (rate limiter bypass with a spoofed X-Forwarded-For). echo v5 fixes both. The panel's API and every agent now run on v5, and govulncheck reports no vulnerabilities.
- The panel already took the client address only from nginx's X-Real-IP header on loopback and ignored X-Forwarded-For; that behaviour is unchanged.
- No change to features, settings or the API.

Update the agent on every server after upgrading the panel, so agents run on the new framework too.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

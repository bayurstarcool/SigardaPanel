SigardaPanel v1.14.0

Database manager for MySQL/MariaDB and PostgreSQL, and phpMyAdmin as an option.

- Databases → Manage, for both engines: browse and filter rows; insert, edit and delete rows (found by their full primary key; only the fields you change are saved); columns, indexes and foreign keys; an SQL console with history; export of the whole database as .sql and import from an upload (up to 30 MB) or a .sql file in the site's folder (any size).
- Everything runs as one of the database's own accounts whose password the panel stores, so it can do exactly what that account can. Row edits, SQL that changes data, exports and imports are written to the audit log (values in SQL are blanked).
- The SQL console is read-only by default: it then runs one statement that only reads (SELECT, SHOW, EXPLAIN, ...) in a read-only transaction. Statements that change data run after a confirmation.
- phpMyAdmin is optional and set up on the panel host with: sudo bash install.sh phpmyadmin (remove it from the panel with: sudo bash install.sh phpmyadmin off; new installs can use INSTALL_PHPMYADMIN=yes). It installs the distribution's phpMyAdmin with PHP-FPM (no Apache), serves it only through the panel at /pma/ and signs in with the database's own account; there is no phpMyAdmin login page. The phpMyAdmin buttons only show when it is installed.
- Security: phpMyAdmin sign-on no longer falls back to the phpMyAdmin control account or creates temporary MySQL accounts that were never removed.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents): the manager needs the new agent.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

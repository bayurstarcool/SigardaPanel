SigardaPanel v1.12.1

Complete and accurate server specifications.

CPU
- Topology comes from the kernel (/sys): online and offline CPUs, sockets, physical cores, threads per core, NUMA nodes. It no longer depends on lscpu's text, which changes between versions (newer util-linux names caches "L3:" in a tree layout, ARM reports clusters, unknown values are "-", minimal images have no lscpu).
- Caches per level (L1d, L1i, L2, L3): size per instance, number of instances and total.
- Clocks: maximum, base, current and minimum (cpufreq on bare metal; lscpu, /proc/cpuinfo or the model name on VMs), and the frequency governor.
- Family, model, stepping, microcode, BogoMIPS; ARM servers and boards (Raspberry Pi) are recognised.
- Notable instruction sets (SSE4.2, AVX, AVX2, AVX-512, AMX, AES, SHA, NEON, SVE), VT-x / AMD-V when exposed, and a CPU limit set on the agent's cgroup.

System and more
- System board and firmware: manufacturer, model, board, BIOS vendor, version and date, chassis type.
- Boot time, load average, process count, time zone.
- Memory modules (size, DDR type, speed, slot) when dmidecode is available.
- Per network interface: link speed, duplex, driver and MTU.
- The Specs page says when a server's agent is too old to report these details.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents); detection runs on the agent.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

SigardaPanel v1.13.0

Every installation has a license, a designed default page for new sites, and security fixes.

Licenses
- License keys are signed by SigardaPanel and verified on your server, offline (Settings → License). Keys accepted before (plain hex) are no longer valid: the panel shows the reason and runs on the free tier.
- Every installation gets a free license automatically: once a day the panel checks in with panel.sigarda.com (a random install id, version, tier, license id, OS/architecture and server/site counts as ranges; no names, domains or emails; Settings → License → "What is sent"). Without internet the panel keeps working; turn it off with SIGARDAPANEL_CHECKIN=off.
- Upgrade plan (Settings → License) opens billing for this installation; once paid, the license arrives on the panel by itself (or with Check now). Renewals arrive the same way.
- Plans, orders, billing and pricing are no longer part of the panel (they live in the master panel).

Sites
- New sites get a designed default page (Tailwind, no external requests) instead of a bare heading; Node.js, Python and Go starters serve it.

Security
- Database charset and collation are validated (changing them accepted any text into ALTER DATABASE); database names, users, hosts, privileges and passwords are built into SQL from allow-lists. Database passwords must now be printable ASCII.
- A site user's terminal starts the login shell with that account's ids and a clean environment (no su).
- PM2 apps must live in a site folder; PHP-FPM socket and log paths are built from allow-listed values.
- Removed unused endpoints that could run commands or SQL as root: the agent's python/manage and the API's databases/exec-sql (and its permission).

Updates
- A panel can take its releases from a private repository with a read-only token (SIGARDAPANEL_UPDATE_TOKEN); public installs are unchanged.

Update the agents on remote servers after updating the panel (Settings → Panel update → Agents).

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").

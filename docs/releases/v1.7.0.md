SigardaPanel v1.7.0

Highlights
- Panel self-update: one-click or automatic within a time window, run history, and one-click rollback.
- Agents can be updated from the panel.
- Site operations run on the site's own server (agent): file manager, vhost editing, logs, disk usage, SSH/FTP jails, site transfer, cron jobs (/etc/cron.d, as the site user) and IP allow/deny lists (server-level, PHP URLs included).
- Backups remember their storage provider, apply exclude patterns, and restores import the backed-up databases (as the site user with the database's own account, never as root).

Security
- Fixes from two full audits, including:
  - symlink and path escapes in restore and the file manager
  - SSRF through agent URLs
  - 2FA brute force
  - tenant admins changing global settings
  - login-lock DoS
  - MySQL account takeover
  - CSRF on cookie sessions
- Go 1.26.11, echo 4.16.4, vite 6.4.6.

SigardaPanel v1.11.1

A quieter, more polished interface. No change to features, permissions or the API.

- Softer neutral colors, a deeper indigo accent and refined status colors, in both light and dark mode.
- Cards and buttons have subtle depth; the sidebar has its own tint and shows the current page as a raised item.
- Clearer typography: larger page titles and figures, compact tables with consistent headers, pill-shaped badges.
- The sidebar no longer shows "PRO" badges on Servers and Users (nothing is restricted by license tier).
- A refreshed sign-in page.

Panels on v1.6.2 or older must update once by hand because of the new signing key (see the v1.7.1 notes):
  curl -fsSLO https://raw.githubusercontent.com/bayurstarcool/SigardaPanel/main/install.sh
  sudo bash install.sh update

Install with the script in the repository README; every file is signed (see "Verifying releases").
